💡 **What:** Added a `SEARCH_INDEX` array that pre-computes a combined, lowercase search string for each exam record upon module initialization, and refactored `searchExams` to use it.

🎯 **Why:** The previous implementation called `.toLowerCase()` four times per record on every single search execution, which is an unnecessary CPU bottleneck.

📊 **Measured Improvement:** Running a benchmark of 1,000 iterations over a 10,000-record mock database revealed a ~3.18x speedup (Original: 63749ms vs Optimized: 20076ms).
